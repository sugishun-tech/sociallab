# 信念の共和国 / BELIEF REPUBLIC

経済に関する知識・誤認・期待・党派性・ネットワーク・投票・政策・景気・分配が相互作用し、**信念が票になり、政策が経済を変え、その結果が再び信念へ戻る**過程を観察するエージェントベースの社会シミュレーションです。

このプロジェクトは `index.html` だけで実行できます。ビルド、サーバー、外部JavaScriptライブラリ、外部APIは不要です。GitHub Pagesにもそのまま置けます。

> **重要**
>
> これは現実社会の予測装置でも、特定政党の勝利を証明する装置でもありません。  
> 未較正の仮定を意図的に可視化し、「どの条件を変えると、どのような政治経済ダイナミクスが生じるか」を調べるための実験室です。

---

## 1. 何をシミュレーションしているのか

各市民は、単なる「右か左か」の1変数ではありません。少なくとも次の状態を持ちます。

- **政策選好 `b ∈ [-1, 1]`**
  - `b > 0`: 規則派 R 寄り
  - `b < 0`: 裁量派 D 寄り
  - `|b|` が小さい: 留保・中間
- **事実認識 `z ∈ [-1, 1]`**
  - 貨幣拡張が長期に残す実質効果についての符号付き推定
  - 世界側の「真値」は `θ = longReal`
- **知識量 `k ∈ [0, 1]`**
  - 情報へ接触し、処理する能力の代理
- **確信度 `c ∈ [0, 1]`**
  - 高いほど新情報で動きにくい
- **党派アイデンティティ**
- **所得・稼得能力**
- **移転受益順位**
- **過去の政策経験**
- **情報ネットワーク**
- **直近の投票行動**

ここで最も重要なのは、**事実認識と政策選好を同一視していない**ことです。

たとえば `z` が世界の真値 `θ` に近くても、自己利益、時間選好、移転の受益、価値判断などが異なれば、同じ政策を支持するとは限りません。逆に、知識量が多くても認識が正しいとは限りません。

---

## 2. R と D は何を意味するのか

この作品では二つの仮想的な政治陣営を置きます。

### 規則派 R

- 貨幣供給を基準ルール `μ₀` に近く保つ
- 裁量的な追加拡張を原則として行わない
- 追加移転が小さい
- 継続的なルール遵守によって「規則への信頼」が回復しうる

### 裁量派 D

- 景気・失業・選挙時期に応じて `μ₀` を超える追加的な貨幣拡張を行いうる
- 追加移転を行う
- 選挙が近いほど、再選志向に応じて刺激を強めうる
- 裁量的な逸脱や政策急変は「規則への信頼」低下や「政策不確実性」を生みうる

**R = 真、D = 偽というラベルではありません。**

世界の真値 `θ` は独立したパラメータです。既定値は `θ = 0` ですが、`θ > 0` や `θ < 0` に変更できます。

## 3. 既定の経済世界

既定設定は、フリードマン的な短期・長期の区別を強く意識した縮約モデルです。

- 長期の恒常的実質効果: `θ = 0`
- 予想外インフレは一時的に産出ギャップへ作用
- 期待が追いつけば、同じ裁量刺激の短期的な実質効果は消耗
- ルールへの信頼が高い規則型政策は期待を基準インフレへ再アンカーしうる
- 裁量的な急変は政策不確実性を増やしうる
- 政策にはラグがある
- 供給ショックと実物景気ショックは金融政策と別に存在する

モデルは完全なDSGE、貨幣需要モデル、金融仲介モデルではありません。**政治学習と期待形成をゲームとして観察するための縮約モデル**です。

## 4. 1四半期に何が起きるか

1期は1四半期です。概略的には次の順で進みます。

```text
外生ショック
    ↓
現政権が政策を決定
    ↓
政策キューへ投入
    ↓  policyLag
過去に決めた政策が実際に作用
    ↓
規則への信頼・政策不確実性を更新
    ↓
期待インフレを更新
    ↓
実現インフレ
    ↓
産出ギャップ・失業率
    ↓
所得・移転・家計経験
    ↓
メディア・ネットワーク・経験から z と b を更新
    ↓
必要なら選挙
    ↓
支持率・正確度・Gini・二極化などを記録
```

政策決定と経済結果の間にラグがあるため、**現在の政権と、現在観測されている経済結果を生んだ政権が一致しない**ことがあります。

その帰属を正しく行える確率が `attribution` です。

## 5. 中核となる経済ダイナミクス

記号は概念を読みやすくするために整理したものです。実装の係数は `index.html` 内にあります。

### 5.1 裁量強度

```text
d = 1{裁量派政権} × (1 - 実効裁量制約)
```

規則派政権では原則 `d = 0`。裁量派でも `binding` や介入「政策ルール」によって裁量を抑えられます。

### 5.2 貨幣増加率

概略:

```text
μ =
  μ₀
  + d × [
      stimulus × (0.25 + 0.75 × reelection × election_phase³)
      + 0.4 × max(u_previous - u*, 0)
    ]
```

選挙が近づくほど `election_phase` は1へ近づきます。

したがって、再選志向が強い裁量派政権では選挙直前の刺激が大きくなります。

### 5.3 インフレ

```text
π_t =
  π_(t-1)
  + κ × (μ_(t-L) - g - π_(t-1))
  + supply_shock
```

- `κ = inflationAdjust`
- `L = policyLag`
- `g = growth`

### 5.4 期待形成

適応的期待では概略:

```text
πe ←
  πe
  + expectationGain × (π - πe)
  + expectationExtrapolation × inflation_momentum
  + reanchor × ((μ₀ - g) - πe)
```

再アンカーの強さは、

```text
reanchor =
  ruleReanchor
  × policyCredibility
  × applied_rule_degree
```

です。

### 5.5 裁量の「賞味期限」

この作品で重要な変更点です。

裁量派の短期便益は、**刺激額そのもの**ではありません。

```text
discretion_short_run_dividend
  = 裁量強度 × phillips × (π - πe)
```

つまり、

```text
期待が遅れる
→ 予想外インフレ
→ 一時的な実質効果
→ Dの短期政治便益
```

は起こりえます。

しかし同じ刺激を反復すると、

```text
期待が追いつく
→ π - πe → 0
→ 短期便益 → 0
```

となります。

これにより、単純な「Dには毎期刺激ボーナス」という構造を避けています。

### 5.6 規則への信頼

`policyCredibility ∈ [0,1]` を状態変数として持ちます。

- 規則を継続的に守ると回復
- 裁量的な逸脱が大きいと低下
- 貨幣増加率の急変が大きいほど信頼損失が強まりやすい

高い規則信頼は、適応的期待を基準インフレへ再アンカーする力になります。

### 5.7 政策不確実性

概略:

```text
policyUncertainty_t =
  0.82 × policyUncertainty_(t-1)
  + 0.18 × (
      |μ_t - μ_(t-1)|
      + 0.5 × |deviation_t - deviation_(t-1)|
    )
```

貨幣増加率の急変やルール逸脱の変化を移動平均化した指標です。

`policyUncertaintyAversion > 0` なら、これが実体経済の調整コストとして産出ギャップを押し下げます。

### 5.8 産出ギャップ

概略:

```text
output_gap =
    0.8 × θ × (μ_(t-L) - μ₀)
  + phillips × (π - πe)
  + real_shock
  - supply_loss
  - rent_loss
  - uncertainty_cost
```

既定 `θ = 0` では、持続的な貨幣拡張そのものに恒常的な実質押上げ効果はありません。

### 5.9 失業率

```text
u = u* - 0.55 × output_gap
```

予想外インフレや実物ショックによる一時的な産出変動が失業率へ反映されます。

## 6. 「知識」と「誤認」のモデル

各市民の `z` は `[-1,1]` です。

この符号付き設計は重要です。真値 `θ = 0` のとき、無知や誤差が必ず「長期効果を過大評価する方向」にだけ出ることを避けています。

### 情報源

市民は以下から更新します。

- 近隣ネットワーク
- 検証されたメディア信号
- 党派的メディア信号
- 政策と経済結果から得た経験的信号
- 公開講座などの介入

### 確認バイアス

現在の自分の見方から遠い情報ほど受け入れにくくなります。

### 有限の受容幅

政策選好の距離が `confidenceBound` を超える相手は、通常の社会学習対象から外れます。

### 誤認の自己増幅

`misperceptionDrift > 0` では、事実認識が毎期真値から遠ざかる力が加わります。

強さは概ね、

- 知識量が低い
- 確認バイアスが強い
- すでに真値から離れている

ほど大きくなります。

## 7. 政策選好の更新

政策選好 `b` は、単純に `z` を政党ラベルへ変換しているわけではありません。

市民は概念的に、裁量派Dの純便益を次の要素から評価します。

```text
Dの知覚純便益
  = 長期便益
  + 短期便益
  - インフレ負担
  - 信頼・不確実性コスト
  - 選挙前の便乗刺激への警戒
  + 私的な移転純便益
  + 社会全体の分配評価
```

その後、

- 社会的同調
- メディア
- 過去の政策実績
- 逆張り
- 確信度
- 忘却

などが加わって `b` が更新されます。

### 忘却

`forgetting` は単なる知識減衰ではありません。

- 事実認識を初期事前信念へ戻す
- 知識量を減衰させる
- 過去の政党実績記憶を弱める
- 学習後の政策選好を初期選好へ少し戻す

ため、安定が長く続くほど過去の失敗の記憶も薄れ、同じ政治サイクルが再発する余地があります。

## 8. 選挙

投票効用は概略、

```text
utility
  = econWeight × (
      1.25 × policy_preference
      + 0.45 × remembered_performance
    )
  + partisanship × party_identity
  + non_policy_component
```

です。

非政策要因には候補者魅力と確率的な揺らぎが含まれます。

### 投票参加

投票参加確率には、

- 基礎投票率
- 投票コスト
- 合理的無知
- 選好の強さ
- 陣営別動員力
- 所得による参加差
- 投票支援介入

が作用します。

そのため、

```text
人口内の支持率
≠ 得票率
≠ 議席比
≠ 実施される政策
```

です。

ここは本シミュレーションの重要な観察点です。

## 9. 選挙制度

### 9地区の小選挙区

地理的に固定された9地区でR/Dの多数決を行います。

- 地区同票: シード付き抽選
- 地区の投票ゼロ: 空席
- 全国の投票ゼロ: 現政権維持

全国得票率で負けても、議席で勝つ可能性があります。

### 全国比例型

全国のR得票率を連続的な議席比として扱います。

このモデルは二党制なので、50%超を得た陣営が政権を取ります。

## 10. 分配と所得

各市民は異なる稼得能力を持ちます。

裁量派Dは追加移転を行い、その原資は比例負担で調達されます。

受益対象はシードで固定された架空の順位によって決まり、現実の人種、性別、職業、地域などとは対応しません。

### 財政錯覚

受給の便益は認識する一方、自分が負担する財源を割り引いて認識する度合いです。

### 貨幣錯覚

家計が名目上の変化を実質改善の一部として知覚する度合いです。

### 格差の累積優位

`inequalityDrift > 0` では、高い稼得能力が相対的にさらに伸び、低い能力は相対的に低下します。

これは現実の格差発生メカニズムを推定したものではなく、**格差が自己増幅する世界を実験するための明示的な仮定**です。

## 11. 主な観測指標

### 人口支持

- 規則派支持: `b > 0.20`
- 裁量派支持: `b < -0.20`
- それ以外: 留保

### 事実認識の正確度

`z` と世界の真値 `θ` の距離を、`z ∈ [-1,1]` の最大誤差で正規化した値です。

これは経済学全般の「知能」ではありません。

### 平均知識量

市民の `k` の平均。

### 二極化度

```text
4 × P(b > 0.65) × P(b < -0.65)
```

両極に強い支持者が同時に存在すると高くなります。

### 陣営をまたぐ縁

ネットワークのうち、符号の異なる政策選好を結ぶリンクの割合。

### 期待ギャップ

```text
|実現インフレ - 予想インフレ|
```

### 所得 Gini

実質可処分所得から計算します。

### 規則への信頼

`policyCredibility ∈ [0,1]`

### 裁量の短期利得

予想外インフレによる一時的産出効果のうち、裁量政策に帰属する部分。

正にも負にもなります。

### 政策不確実性

政策急変・ルール逸脱変化の移動平均指標。

### 生活指数

概略:

```text
実質可処分所得の幾何平均
× インフレ不安定性ペナルティ
× 政策不確実性ペナルティ
```

を初期値100に正規化したものです。

これは現実の厚生指標ではありません。

## 12. シナリオ

| `lag` | 見えない政策効果 | 選挙は2年ごと、政策は3年後。誰が評価され、誰が責められるか。 |
| `shockhell` | ショック地獄 | 供給危機と実物景気ショックが頻発。政権の責任と外生要因の区別が難しくなる。 |
| `lighthouse` | 知識の孤島 | 正確に理解する少数の拠点。その知識は周囲へ伝わるか。 |
| `silentexperts` | 賢者は棄権する | 理解の質は高い。しかし投票コストが高く、知識がそのまま得票へ変換されない。 |
| `advertising` | 広告の大洪水 | 裁量派寄りの情報があふれる国。露出と真偽を切り分けて観察する。 |
| `fortress` | 制度防波堤 | ショックは多いが、裁量制約・検証情報・政策帰属が強い。悪条件の中で制度がどこまで耐えるか。 |
| `open` | 透明な社会 | 正確な情報、広い対話、低い党派性。それでも利害の違いは残る。 |
| `learningturn` | 刺激の賞味期限：D→R | 最初は裁量刺激が魅力的。しかし期待が追いつき、信頼損失とインフレ負担が蓄積すると政治評価が反転しやすい。 |
| `amnesia` | 忘却の振り子 | 裁量の代償を学んでも記憶が薄れる。規則で安定すると危機の記憶も消え、再び刺激へ惹かれる政治循環が起きうる。 |
| `counterfactual` | 反実仮想：貨幣は中立でない | 世界の仮定そのものを変更。長期の実質効果を持たせた比較用の国。 |

### 特に見る価値がある動学シナリオ

#### 刺激の賞味期限：D→R

初期には裁量刺激が政治的に魅力を持ちますが、

1. 期待が追いつく
2. 予想外インフレが縮小する
3. 裁量の短期利得が消える
4. 信頼損失・インフレ負担・政策不確実性が残る
5. 有権者が正しく帰属できれば評価が反転する

という経路が発生しえます。

「最初からRが勝つように設定したシナリオ」ではなく、**Dの短期優位が内生的に消耗するか**を見るためのものです。

#### 忘却の振り子

1. 裁量政策の代償を経験
2. Rへ政権交代
3. 安定が続く
4. 過去の危機・政策実績の記憶が薄れる
5. 短期刺激の魅力が再び強く見える
6. Dが復活する可能性

という政治循環を観察します。

#### 認識腐食スパイラル

知識量が完全にゼロでなくても、確認バイアス・情報環境・誤認ドリフトの組合せで、正確度だけが継続的に崩壊する状況を観察します。

#### 期待アンカー崩壊

インフレ変化を過度に外挿し、期待が実現値を追い越して振動する世界です。

#### 超格差社会：金色の断崖

所得格差そのものに累積優位を持たせ、さらに所得差を投票参加率へ接続します。

## 16. A/B比較実験

「A/B 比較実験」では、**1パラメータだけを変えて複数シードで比較**できます。

例:

```text
A: expectationGain = 0.08
B: expectationGain = 0.58
観測期間: 80期
各条件: 16回
```

A/Bでは、

- 同一ペアのシード
- 共通の外生ショック系列

を使います。

ただし、個々の市民の信念更新や投票は途中の分岐によって乱数消費位置が変わりうるため、完全な決定論的ペア差分ではありません。

表示される標準偏差は**シミュレーション実行間のばらつき**です。

現実社会の推定誤差、信頼区間、因果効果の標準誤差ではありません。

### おすすめ実験

#### 期待形成速度

`expectationGain`

裁量刺激の短期的政治利益が何期持続するかを見る。

#### 忘却率

`forgetting`

一度学習した社会が再び同じ政策へ戻るかを見る。

#### 政策帰属精度

`attribution`

政策ラグがある社会で、有権者が誰を評価・処罰するかを見る。

#### 確認バイアス × 同類選好

`confirmation`, `homophily`

情報の正確性とは別に、ネットワーク構造だけで分断が維持されるかを見る。

#### 規則信頼

`credibilityGain`, `credibilityLoss`, `ruleReanchor`

ルールが単なる政策制約ではなく、期待形成装置として働く条件を見る。

#### 格差と政治参加

`inequalityDrift`, `turnoutIncomeBias`

所得分布の変化が投票者集団の構成をどう変えるかを見る。

シード付き擬似乱数を使います。

描画用の速度・フレームレートは経済モデルを進める乱数とは分離されています。

## 21. 観測実績

ゲーム的な観察目標として実績があります。

- **知識の灯台**: 正確度80%・知識50%を8期維持
- **壁の向こうへ**: 異陣営の縁25%・二極化10%未満を8期
- **票のねじれ**: 支持と得票が15pt乖離、または得票と政権が逆転
- **二つの島**: 二極化度65%以上
- **政権交代**: 選挙で政権交代
- **長期を生きる**: 64期 = 16年間を観測
- **真実の腐食**: 事実認識の正確度35%未満
- **期待の暴走**: 期待ギャップ10pt超
- **金色の断崖**: 所得Gini 0.65超

実績は「良い結果」を意味しません。社会状態を観測した記録です。

## 26. モデルを読むときの注意

### 単一実行を結論にしない

シードを変えると結果は変わります。

「この実行でRが勝った」から、

```text
現実でもRが正しい
```

とは言えません。

同様にDについても言えません。

### パラメータは推定値ではない

多くの係数は、現象を分離して観察するための未較正パラメータです。

たとえば、

```text
confirmation = 0.48
```

だから現実の確認バイアスが48%だ、という意味ではありません。

### 因果方向を埋め込んでいる部分がある

たとえば、

- 規則遵守 → 信頼回復
- 政策急変 → 不確実性
- 誤認ドリフト → 真値から離れる
- 格差累積優位 → 所得分布拡大

などは明示的なモデル仮定です。

これらを0にして無効化し、結果がどの程度変わるかを見るのが重要です。

### 政治は二陣営へ強く圧縮されている

現実の政治争点は多次元です。

この作品は、

```text
貨幣ルール / 裁量
短期刺激 / 長期安定
移転
情報
期待
```

の相互作用を見るため、政治空間を意図的に圧縮しています。

## 27. このモデルで特に調べたい問い

この作品の中心テーマは「どちらが勝つか」より、次です。

### 正しい情報はいつ生き残るか

- 検証情報を増やせば十分なのか
- 確認バイアスが強ければ意味がないのか
- 知識拠点が孤立すれば社会へ広がらないのか

### 裁量刺激の政治的寿命は何で決まるか

- 期待形成速度
- 政策ラグ
- 貨幣錯覚
- 政策帰属
- 忘却
- 選挙周期

### なぜ失敗した政策が復活するのか

- 忘却
- 世代交代に相当するノイズ
- 安定による危機記憶の消失
- 新しいショック
- 党派性

### 規則はなぜ支持されうるのか

単純な「Rに+点」ではなく、

- 期待の再アンカー
- 信頼
- 不確実性低下
- 時間的不整合への警戒
- 裁量利益の消耗

から内生的に支持が形成されるかを見ます。

### 格差は政策だけでなく有権者集合を変えるか

所得格差が投票参加差へ接続されると、

```text
人口全体の選好
```

と

```text
実際に投票した人の選好
```

が乖離します。

## 31. 最後に

このシミュレーションで重要なのは、

```text
どの陣営が勝ったか
```

だけを見ることではありません。

見るべきなのは、

```text
なぜ勝ったのか
どの状態変数が先に動いたのか
期待は追いついたのか
知識と投票は一致したのか
支持と議席は乖離したのか
政策効果を正しい政権へ帰属できたのか
一度学んだことを社会は忘れたのか
```

です。

同じ社会でも、

```text
知識
→ 信念
→ 投票
→ 政策
→ 経済
→ 経験
→ 知識
```

という循環のどこを少し変えるかで、長期の政治均衡は大きく変わります。

**勝者を決めるゲームではなく、勝者を生み出す制度・期待・情報・記憶の構造を見るゲームです。**
